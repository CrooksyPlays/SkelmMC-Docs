The roadmap exists so users can distinguish the project's intended direction from features verified in a release. Its priorities are provisional and can change after implementation testing.

## Phase 1 — Reliable foundation

- Verify plugin startup and inventory interactions on target Paper builds.
- Establish a stable command and permission architecture.
- Define configuration defaults and reload behavior.
- Implement consistent server prefix and editable messages.
- Finish a maintainable GUI action/registry pattern.

## Phase 2 — Everyday essentials

- Home, warp and spawn teleportation.
- Teleport warmups, cancellation and permission rules.
- Heal, feed and god-mode utilities.
- Persistence for user preferences and saved locations.
- Automated checks for commands, menu clicks and server version support.

## Phase 3 — Optional modules

- Configurable GUI shop with safe economy integration.
- Optional module boundaries for installations that do not need every feature.
- More sophisticated menu templates and server navigation.
- Additional server management utilities based on feedback.

## Documentation automation

A future CI step can extract commands, permissions, version requirements and supported config keys directly from the plugin repository. Those verified data files can become public reference pages automatically. Hand-written guides can remain in Markdown.

## Planning for multiple plugins

The site already groups articles by project. As other SkelmMC plugins emerge, add their sections here rather than starting an unrelated documentation site for each one.
