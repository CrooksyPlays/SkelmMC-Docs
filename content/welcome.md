SkelmMC Docs is the central knowledge base for all SkelmMC projects: plugins, shared tools, guides, command references, configuration examples, and release notes. Each project has its own section, so you can find the information you need without digging through Discord messages.

## What lives here?

- **Guides:** clear setup steps and explanations for common server-owner tasks.
- **References:** commands, permission nodes, settings and examples organized by feature.
- **Compatibility:** server requirements and version-specific warnings.
- **Release notes:** verified changes and migration guidance as the plugin evolves.

## How the documentation is organized

Use the left sidebar to navigate between topics, or press **Ctrl+K** (Windows/Linux) or **⌘ K** (Mac) to search across the entire site. The right sidebar links to headings on the current page. Each article has next/previous navigation at the bottom.

## Adding another plugin

Every plugin can have its own section under the same website and appear in global search. Add Markdown articles under `content/your-plugin/` and register them in `site.yml`. See [Using the docs](../platform/how-to-use/) for the editing process.
